FrontAccounting ERP – Manual Testing Project

Project Overview
FrontAccounting ERP is a web-based, open-source ERP application used by small and medium-sized businesses to manage their daily business operations.

Project Description
FrontAccounting helps manage business activities such as sales, purchases, inventory, accounting, banking, customers, suppliers, and financial reports.

This project focuses on manual testing of the Login, Sales, Purchase, and Items & Inventory modules.

Modules and Sub-Modules Covered

 1. Login
- Login

 2. Sales
- Sales Quotation Entry
- Sales Order Entry
- Delivery Against Sales Order
- Invoice Against Delivery
- Customer Payment Entry

 3. Purchase
- Purchase Order Entry
- Outstanding Purchase Orders Maintenance
- Suppliers Invoice
- Payments to Suppliers

 4. Items & Inventory
- Inventory Location Transfers
- Inventory Item Movements
- Inventory Items Status

System Workflow
Sales Workflow
Sales Quotation Entry → Sales Order Entry → Delivery Against Sales Order → Invoice Against Delivery → Customer Payment Entry

Purchase Workflow
Purchase Order Entry → Outstanding Purchase Orders Maintenance → Suppliers Invoice → Payments to Suppliers

Items & Inventory
This module manages inventory location transfers, tracks item movements, and monitors item status.

Testing Activities-
- Writing test scenarios and test cases
- Testing valid and invalid inputs
- Verifying expected and actual results
- Identifying and reporting defects
- Assigning severity and priority to defects

Project Type
Manual Software Testing
